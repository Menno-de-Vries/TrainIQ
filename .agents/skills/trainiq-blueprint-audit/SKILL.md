name: trainiq-blueprint-audit
description: Use when comparing the TrainIQ Android app against TrainIQ_Target_State_Blueprint.md; produces a requirements matrix, gap list, implementation priority, and verification plan.
---

Use this skill to:
- read the TrainIQ blueprint as the source of truth;
- extract all requirements into stable requirement IDs;
- map each requirement to current files, screens, flows, models, state, navigation, tests, and validation methods;
- classify each requirement as satisfied, partial, missing, blocked, or unclear;
- prioritize gaps by dependency order, user impact, implementation risk, and verification ease;
- output compact structured findings, not long transcripts.
