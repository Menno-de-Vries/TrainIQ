# TrainIQ

TrainIQ is an Android health coaching app that combines local training, nutrition, progress, Health Connect, and explicit Gemini-powered coaching flows.

The Android project lives in `TrainIQ-Project`.

## Quick Start

```powershell
cd .\TrainIQ-Project
.\gradlew.bat :app:assembleDebug --console=plain
.\gradlew.bat :app:testDebugUnitTest --console=plain
```

See `TrainIQ-Project/README.md` for Android SDK setup, Health Connect emulator notes, Gemini key setup, connected tests, lint, and release signing readiness.
